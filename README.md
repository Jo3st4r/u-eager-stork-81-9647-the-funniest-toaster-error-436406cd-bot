## The error

> ERROR E-07: Toast ejected early. It has requested a transfer to a kitchen that respects it.

1 error code, 2 slices, 0 respect: a real appliance message
first — an error code, a flat fault report — then the quiet
turn: the toast has not failed, it has filed a transfer
request to a kitchen that respects it. Funny because it is
deadpan, original because the bread is the one complaining,
and tight because every word earns the code it sits under.
